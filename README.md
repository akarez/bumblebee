<h1 align="center">bumblebee</h1>

<p align="center">
    The bumblebee is a wireless mechanical keyboard PCB designed as a drop-in replacement for the RAMA M6. It features the nRF52840 SoC, nPM1300 power management IC, and a 2.4GHz chip antenna. The keymaps can be configured with ZMK and GitHub actions.
